# sprint5-dashboard
Dashboard de análise de anúncios de carros.
As funcionalidades são:
1. Criação de um histograma - permite identificar a distribuição por kms dos veículos;
2. Criação de um gráfico de dispersão - permite analisar a razão da quilometragem e o preço dos veículos.
